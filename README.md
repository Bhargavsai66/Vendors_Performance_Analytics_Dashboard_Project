#Vendors_Performance_Analytics_Dashboard_Project:
This project analyzes vendor performance using Python, Power BI, and EDA. It identifies top vendors, underperforming brands, and bulk purchasing effects while optimizing sales, profit, and inventory turnover. The report and dashboard provide insights to improve efficiency and reduce losses.

###Here’s the Step-by-Step Process:

Vendor Performance Analysis – What was Done

###Step-1: Data Collection
   I gathered vendor sales data from `vendor_sales_summary.csv` and other sources for analysis.

###Step-2: Data Cleaning
   I removed duplicates, fixed missing values, standardized columns, and ensured correct data types for accurate analysis.

###Step-3: Feature Engineering
   I created key metrics like **Profit, Margin, Unit Price, Order Size**, and turnover indicators to evaluate vendor performance.

###Step-4: Exploratory Data Analysis (EDA)
   I used Jupyter notebooks to explore sales trends, visualize top vendors, detect underperforming brands, and study bulk purchase impacts.

###Step-5: Vendor Performance Summary
   I aggregated data at the vendor level to calculate **total sales, total profit, average margin, and order volumes**, and ranked vendors based on performance.

###Step-6: Dashboard Creation
   I developed an interactive **Power BI dashboard (`vendor_performance.pbix`)** that highlights KPIs, sales trends, top/bottom vendors, and detailed drilldowns.

###Step-7: Reporting
   I documented findings in the **Vendor Performance Report (PDF)**, presenting business problems, analysis, results, and recommendations for improving vendor efficiency.

###Step-8: Outcome
   The project provided actionable insights: identifying top vendors, spotting underperforming brands, optimizing bulk purchases, and improving inventory turnover to reduce costs and increase profitability.
